## Румсервер

Репитер, который хранит у себя последние N сообщений и выдает их всем подключившимся. Позволяет настроить доступ по
паролю. В теории может выполнять роль чата из которого можно получить сообщения, которые ты пропустил, пока был в
оффлайне.

На практике использование сомнительное т.к. создает большую нагрузку на сеть при передаче старых сообщений. На текущий
момент не используется в сети.

## Бридж

С т.з. сети не является отдельной ролью. По факту это прошивка репитера с функцией ретрансляции не только по LoRa, но
и по другим каналам. Делается это с целью соединить несколько репитеров, которые находятся рядом но по какой-то причине
не могут быть соеденены через LoRa. Например разные частоты или разные диаграммы направленности.

Так работает соединение сетей на частоте 433MHz и 868MHz. Компаньон на 4ке подключается к репитеру на 4ке, дальше пакет
расходится по репитерам 4ок. Некоторые из репитеров являются бриджами, они передают сообщение на соседний репитер 8ку
и оттуда сообщение расходится уже по сети на 8ке.

User-4M -> Bridge-4M -> Bridge-8M -> User-8M

Самый распространенный способ реализации соединения - через EspNow. Он работает на платах с ESP чипами.
Тогда два устройства соединяются по другому радио (WiFi или аналогичное на 2.4GHz). Но есть и варианты с проводным
соединением.

## Наблюдатель

Как и бридж не является отдельной ролью с т.з. сети. Это прошивка репитера, которая умеет подключаться к WiFi и
передавать статистику MeshCore сети в интернет. Наблюдатели помогают видеть связи в сети.

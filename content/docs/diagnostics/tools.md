# Инструменты

## Трассировка

Трассировка -- способ оценить слшимость между конкретными узлами сети.
Чаще всего тестируется связь между двумя узлами, но технически узлов может быть сколько угодно. Тестировать можно как
симметричные, так и асимметричные пути.

* Симметричный: A -> B -> C -> B -> A
* Асимметричный: A -> B -> C -> A

Интерфейс трассировки может отличаться между клиентами, поэтому разберем пару примеров.

### MCO Advanced

Инструмент трассировки запускается иконкой на верхней панели.
Затем кликаем на ноды из которых мы хотим построить цепочку.
По какой-то причине в MCOA нельзя добавить одну и ту же ноду дважды через клики, но можно дописать адрес руками.

Когда путь готов есть два способа запустить трассировку:

1. Левая кнопка запускает путь с нодами слева направо.
   В таком случае предполагается, что компаньон сам слышит последнюю ноду.
2. Средняя кнопка запускает симметричную трассировку.
   Т.е. пакет пройдет всю цепочку в одну сторону, а потом вернется по ней назад.

### Официальный клиент

Тут все чуть проще. Выбираем инструмент "Trace Path - Using Map" и просто кликаем по нодам в том порядке, в каком хотим
проверить путь. Если нужно провести симметричный путь, то нужно самостоятельно прокликать путь назад.

Но отображение результата тут читать сложнее чем в MCOA т.к. уровни сигнала подписаны на карте и не всегда понятно,
какое из значений какое направление связи отображает.

# Настройки радио

Сайт для первоначальной настройки репитера через USB: config.meshcore.io

## Частотный план

Прим: Coding rate можно повысить на компаньоне если слышите, но не добиваете до ретрансляторов

Частота 868.731 МГц
Полоса 62.5 кГц

### 433MHz

Частота 434.300
Полоса 62.5
[Spreading factor](/docs/settings/metrics#spreading-factor) 9

Настройки для репитеров (через удаленное управление вашим компаньоном):

Manage -> Sync clock - обязательно! Необходимо выполнять синхронизацию времени после сброса питания репитера для корректных временных меток пакетов и [адвертов](/docs/vocabulary#адверт)!

Manage -> Advert Intervals:
Auto advert (zero hop) - 240 (минут)
Auto advert (flood) - 12 (часов)

Position: укажите позицию вашего репитера (хотя бы приблизительно) для корректного отображения на картах.

-----

В консоли управления укажите следующие параметры для репитера:

set path.hash.mode 1 - включение рассылки рекламы в двухбайтовом режиме.

set tx x -
(где х -требуемая мощность в дБ на ЧИПЕ, по умолчанию установлена 22)
set flood.advert.interval 12 - 12-часовой период широковещательных адвертов
set advert.interval 240 - 240 минут для прямого адверта
set txdelay 1.0 - минимально возможная задержка, 4 окна по 250 мс (меньше шанс коллизий)
set rxdelay 0.7 - ожидание обработки пакета до прихода более «сильного» эхо
set multi.acks 1
Опционально:
set agc.reset.interval 16 , где 16 - интервал сброса АРУ в секундах, устраняет проблемы с чувствительностью при слишком сильных сигналах рядом. Подбирается индивидуально, значение должно быть кратно 4 желательно ставить не меньше 8 или 16. Особенно актуальна эта настройка для плат с встроенным усилителем на прием (heltec v4, e22).

Про `txdelay` и `rxdelay` подробнее читай в разделе [Тайминги](/docs/settings/timings).

---------------------------

Для компаньона (абонентская станция) необходима только настройка радио (см. выше) и название узла. Установите режим 2 байтовой маршрутизации:

Настройки компаньона -> Экспериментальные настройки -> Размер хэша маршрута по умолчанию - 2 байта (32 хопа).
Настройка производится из мобильного приложения!

По желанию устанавливаются координаты, для рассылки геопозиции включите галочку "share position in advert".
Объявление о себе (advert) рассылается только инициативно самим пользователем.
Если вы хотите чтобы ваш контакт увидели другие участники сети, не забывайте периодически его рассылать методом Flood.
Рассылка производится нажатием кнопки со значком радио в верхнем правом углу приложения.

### Удалённое управление репитером

После завершения настройки компаньона вы можете управлять репитером удалённо — по радио, не подходя к нему:

1. В приложении выберите репитер из списка контактов.
2. Нажмите кнопку «Manage».
3. Вводите команды прямо из телефона — они уйдут по радио.

## Правила именования устройств

Названия узлов состоят из названия узла и трех префиксов:

[Название]-[1][2]-[3], где:

Префикс 1 — частота узла: "4" для 434 МГц, "8" для 868 МГц.
Префикс 2 — тип узла: "M" - компаньон, "R" - репитер. "B" - бот.
Префикс 3 — опционально, направление антенны в морской нотации (N, NW, S, SE, W итд).

Примеры записи:
* AwesomeStreet-4R (репитер на 434)
* Bulvar-8R-SW (репитер на 868, направление юго-запад)
* CoolMan-8M (носимый компаньон на 868)

# Тайминги (txdelay / rxdelay)

Команды задаются в консоли управления репитера.

## txdelay

`txdelay` регламентирует максимальное время для выбора окна передачи. Тем самым получаются несколько временных окон для ретрансляции (по 250 мс):

* при `0.5` их всего два;
* при `1.0` — уже четыре.

Больше окон не значит, что передача станет дольше — она всегда занимает одно окно. Просто при случайном выборе временного окна ретрансляции появляется возможность подождать подольше, что снижает шанс сбить передачу. Когда соседей много, велик шанс коллизий — поэтому увеличение `txdelay` помогает.

* `1.0` — 4 окна по 250 мс. Минимально возможная задержка, меньше шанс коллизий.
* Большие значения — резерв на случай перебивания вашего репитера соседями.

## rxdelay

Ожидание обработки пакета до прихода более «сильного» эха.

## Рекомендации

Стандартная настройка:

* `set txdelay 1.0`
* `set rxdelay 0.7`

Опционально — `txdelay` можно увеличить до больших значений (максимум 3) при подозрении на перебивание вашего
репитера соседями. Имеет смысл при нахождении репитера на малой высоте и при наличии большого количества соседей
с SNR>0.

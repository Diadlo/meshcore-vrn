# Каналы

## Публичные каналы

### #public

Общалка для новичков, виден на карте покрытия (MeshCartel).

### #public_mco

Чат с поддержкой сжатия MCMP v3 (только для [MCO Advanced](https://t.me/mcoadvanced)). Настройка канала — в разделе [про MCO Advanced](/docs/clients#mco-advanced).

### #links

Чат для пингов и ботов.

### #warning

Чат с оповещениями об опасности. Оффтоп не приветствуется.

### #memes

Чат с мемами.

### #viktorina

Викторина.

### #tourism

Канал для туристов.

## Приватные каналы

### vrnTalks

Общалка.

* Название: `vrnTalks`
* Ключ: `0ef0b7a67537fefc9db717ecef69a6d3`

В vrnTalks рекомендуется использовать сжатие Cyr2Lat: оно заменяет некоторые кириллические символы на латиницу, облегчая вес пакета.

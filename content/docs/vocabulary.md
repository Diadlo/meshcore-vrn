# Словарь

**Нода**
: От `node`, само устройство, на котором запускается MeshCore.

**Адверт**
: От `advert`, отправка нодой информации о себе в сеть, может содержать геопозицию.

**Компаньон**
: От `companion`, нода с прошивкой клиента, через которую вы попадаете в сеть, подключившись смартфоном или компьютером.

**Репитер** (репа)
: От `repeater`, нода с ролью ретранслятора, передаёт пакеты в сети другим ретрансляторам и нодам. У репитера есть префикс (первые байты публичного ключа, 2–4 символа), по этим префиксам строится маршрут прохождения пакета.

**Четверка** (4ка)
: Устройствo на частоте 433MHz

**Восьмерка** (8ка)
: Устройствo на частоте 868MHz

**Пакет**
: От `packet`, любая полезная информация в сети: сообщение, адверт, другие служебные пакеты с данными.

**Личка**
: Личные сообщения между двумя пользователями.

**Директ**
: От `direct`, когда пакет данных прошёл между нодами напрямую.

**Флуд**
: От `flood`, когда пакет данных идёт не по конкретному маршруту, а передаётся всеми репитерами в сети. Этот способ используется при отправке сообщений в каналах.

**Хоп** (прыжок)
: От `hop`, количество промежуточных ретрансляций (репитеров по пути пакета). Если пакет прошёл между нодами напрямую — это директ или `zerohop`.

**Маршрут** (путь)
: Список префиксов репитеров, через которые прошёл пакет данных. Длина маршрута — это количество хопов.

**Аск**
: От `ACK`, подтверждение доставки сообщения (в личных сообщениях).

**Лора**
: Разговорное название LoRa.

**Мышь** (тастик)
: Разговорное название Meshtastic-сети.

**Окурок** (огрызок)
: Обычно комплектная с нодой маленькая антенна с посредственными характеристиками. Подходит только для тестирования, чтобы не повредить передатчик.

**Палка**
: Антенна в виде прямой палки, обычно с хорошими характеристиками.

**Яга**
: От `Yagi`, антенна типа «волновой канал».

**Моксон**
: От `Moxon`, антенна Моксона.

**Вардрайвинг**
: От `wardriving`, процесс поиска покрытия сети в городе.

<a id="пигтейл"></a>
**Пигтейл**
: От `pigtail`, короткий тонкий кабель, соединяющий плату с разъёмом антенны на корпусе ноды. Довольно хрупкий.

**Нановна**
: От `NanoVNA`, сетевой векторный анализатор цепей и антенн.

**Жидкий**
: Сленговое название ноды `Seeed Studio SenseCAP T1000-E`.

Позаимствовано из [словаря MeshCore Санкт-Питербург](https://meshcore.spb.ru/wiki/vocabulary)

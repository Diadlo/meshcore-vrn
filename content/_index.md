# MeshCore Воронеж

MeshCore - это кроссплатформенная система для обеспечения безопасной текстовой связи с использованием
LoRa-радиооборудования для обмена сообщениями на дальних расстояниях с низким энергопотреблением.

В MeshCore используется разделение узлов в сети по ролям. Основных роли две:

* [компаньон](/docs/roles#Компаньон) (чат-клиент) – пользовательское устройство для связи с сетью;
* [репитер](/docs/roles#Репитер) (ретранслятор) – узел, передающий весь трафик в сети.

Пользователям доступны публичные и приватные групповые каналы, личные сообщения с шифрованием, обмен геопозицией и
другой телеметрией по запросу. До 64 хопов для доставки сообщений!
